# Security Policy

RoadSense-Perception is currently a local fixture service and a static Pages
demo; it is not an internet-facing inference endpoint. Do not upload private
images, credentials, model weights, or licensed datasets to the public demo.

The detailed threat model and planned hardening controls are in
[docs/SECURITY.md](docs/SECURITY.md). Before a public repository is enabled,
security reports should be sent through a private GitHub Security Advisory or
another private channel rather than posted with exploit details in an issue.
